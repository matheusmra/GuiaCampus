# Artefatos do Projeto

Este diretorio mantem os artefatos produzidos ao longo do projeto. Liste os artefatos com suas localizacoes e descricao do conteudo.

## Exemplos de organizacao

**Artefatos de gestao e reunioes:**

* `/atas` - Atas de reuniao.
* `/canvas` - Canvas de modelo de negocios, proposta de valor ou definicao do problema.
* `/cronograma` - Planejamento, entregas e acompanhamento das atividades.

**Artefatos tecnicos:**

* `/diagramas` - Diagramas de casos de uso, classes, sequencia, componentes, arquitetura, banco de dados ou fluxo.
* `/especificacoes` - Documentos de requisitos, APIs, telas, historias de usuario ou regras de negocio.
* `/prototipos` - Prototipos de interface, wireframes ou fluxos de navegacao.
* `/experimentos` - Registros de execucoes, metricas, comparacoes e resultados, quando aplicavel.

**Outros:**

* Crie diretorios conforme os artefatos exigidos pela disciplina e descreva-os neste arquivo.
