# Codigo do Projeto

Mantenha neste diretorio os arquivos necessarios para implementar, executar, testar ou reproduzir a solucao computacional do projeto.

Cada equipe deve organizar esta pasta conforme as exigencias da disciplina e a natureza do projeto. Por exemplo, esta pasta pode conter codigo-fonte de aplicacoes, APIs, frontend, backend, jogos, algoritmos, scripts, notebooks, testes, dados de exemplo, configuracoes ou experimentos computacionais.

Descreva neste README a estrutura adotada pela equipe, incluindo:

* Principais diretorios e arquivos.
* Linguagens, frameworks, bibliotecas e ferramentas utilizadas.
* Dependencias necessarias.
* Variaveis de ambiente ou arquivos de configuracao, quando existirem.
* Comandos para instalar, executar e testar o projeto.
* Instrucoes para preparar dados ou reproduzir experimentos, quando aplicavel.
