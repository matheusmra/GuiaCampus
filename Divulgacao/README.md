# Divulgacao do Projeto

Use este diretorio para arquivar os materiais de divulgacao do projeto, conforme as orientacoes da disciplina.

Esta pasta pode conter apresentacoes, videos, imagens, capturas de tela, banners, pitch, poster, roteiro de demonstracao, material para redes sociais ou outros arquivos usados para comunicar o projeto e seus resultados.

Crie subdiretorios conforme a necessidade da equipe ou exigencia dos professores, por exemplo:

* `/apresentacao`
* `/video`
* `/imagens`
* `/poster`
* `/demo`

Inclua apenas materiais produzidos pela equipe ou com permissao de uso.
